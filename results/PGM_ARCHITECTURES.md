# DP-PGM architectures: everything in one place

Generated by `scripts/pgm_architectures.py` from every DP-PGM sweep CSV; one row per target in `results/pgm_architectures.csv`.  Rerun it after any sweep.  Only DP-edge targets built with the fixed edge estimator are included (see `results/BROKEN.md`).

## The architectures

| architecture | tables measured | how the tables are chosen | DP end to end | targets |
|---|---|---|---|---|
| 1-way only | a 1-way table per gene + the label marginal (genes independent, no label link) | fixed | yes | **not run** |
| Star (last year's winner) | 978 gene 1-way + 978 (gene, label) | fixed by config | yes | 84 |
| Label-only star | 978 (gene, label), no 1-way | fixed | yes | 8 |
| Star + DP gene tree | star + 977 (gene, gene) spanning tree | MST-style exponential mechanism | yes | 72 |
| Star + DP gene-gene-label tree | star + 977 (gene, gene, label) triangles | MST-style exponential mechanism | yes | 72 |
| k/l forest | k (gene, label) + l (gene, gene) + 1-way for uncovered genes | DP top-k + DP truncated Kruskal | yes | 280 |
| Star with hairs | l (gene, gene) + one (gene, label) per component [+ every 1-way]: a spanning tree over genes + label | DP truncated Kruskal + DP hub per component | yes | **not run** |
| PQRS (Steven's k-way) | star + n2 (gene, gene) + n3 3-way + n4 4-way | Spearman ranking, NOT DP | no (selection) | 4 |
| Classic MST (label as a free node) | spanning tree over genes + label, label edges compete with gene edges | MST | yes | **not run** |

All run in joint mode (one model, label as a node) under rho-zCDP, add/remove neighbours, 0.1 of rho on DP bin edges and (where tables are chosen from data) 0.3 on selection.

## Reading the columns

- **utility**: TSTR macro-F1 over train-on-real (1 = as good as real).
- **corr MAE**, **W1**: gene-gene correlation error and mean per-gene Wasserstein distance (lower is better).
- **discrim.**: AUC of a real-vs-synthetic classifier (0.5 = indistinguishable).
- **MahalaMIA**: best of its covariance variants (an upper envelope).
- **v2 black / v2 black+grid / v2 white**: MAMA-MIA v2, class-centred, one fixed path each (no maximum over paths).  Black box: the star's tables are public; data-dependent tables are guessed by held-out shadows; edges are release quantiles (black) or the grid estimator (black+grid).  White box: the true tables on the true edges.  DP bound at eps=10: 0.89.
